|dsf-logo| Team
===============

DSF is a scientific software package developed and maintained within
the `LSST Dark Energy Science Collaboration (DESC) <https://lsstdesc.org/>`_.
Its development is a collaborative effort, bringing together contributions
to the modelling, implementation, validation, and documentation of
galaxy–galaxy lensing forecasts.

Contributing
------------

DSF welcomes contributions from members of DESC and the wider
scientific community.

See the :doc:`contributing` guide for development instructions,
testing, documentation, and pull request guidelines.

Issues and feature requests can be submitted through the
`DSF GitHub repository <https://github.com/LSSTDESC/dsf>`_.
